# REGRA: POLÍTICA DE SUBIDA PARA O GITHUB (GIT PUSH)

## Diretriz Obrigatória
1. **Proibição de Push Automático:** O assistente NUNCA deve executar comandos de push para o GitHub (`git push`) por iniciativa própria.
2. **Ciclo de Testes Primeiro:** Todas as alterações devem ser implementadas e testadas localmente.
3. **Solicitação Expressa do Usuário:** A subida para o GitHub só pode ocorrer quando o usuário solicitar explicitamente após a validação e homologação dos testes.
